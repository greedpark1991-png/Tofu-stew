# 병맛 동물 격투게임 v2

2~4명이 링크로 같은 방에 들어와 플레이하는 2D 도트 쿼터뷰 난투게임입니다.

## 캐릭터
- 찌개: 갈색 말티푸 / 묵직한 균형형
- 감자: 크림색 토이푸들 / 빠른 스피드형
- 만두: 하얀색 푸들 / 높은 점프
- 종은이: 주황+하양 고양이 / 날렵한 난투형

## 조작
- WASD / 방향키: 이동
- J: 주먹
- K: 발차기
- L: 박치기
- Space: 점프
- 공중에서 K: 점프발차기
- Shift: 대시

## 규칙
맞을수록 데미지 %가 올라가며 더 멀리 날아갑니다. 장판 밖으로 크게 날아가면 KO. 5 KO 선승입니다.

## 혼자 테스트
방을 만든 뒤 `연습용 봇 추가`를 눌러 바로 전투를 테스트할 수 있습니다.

## Render 업데이트
기존 GitHub 저장소의 `byeongmat-animal-brawler` 폴더를 이 버전으로 덮어쓰면 Render가 자동 배포합니다.

Root Directory는 기존과 동일하게:

`byeongmat-animal-brawler`

Docker 배포를 그대로 사용하면 됩니다.
