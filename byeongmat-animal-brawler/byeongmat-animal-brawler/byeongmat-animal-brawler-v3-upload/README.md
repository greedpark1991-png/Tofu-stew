# 병맛 동물 격투게임 v3

브라우저에서 2~4명이 실시간으로 싸우는 2D 도트 쿼터뷰 난투게임입니다.

## v3 변경점
- 캐릭터 4종 실루엣/비율 분리
  - 찌개: 갈색 말티푸, 덥수룩한 귀와 털
  - 감자: 2개월 크림 토이푸들, 다른 캐릭터보다 확실히 작음
  - 만두: 하얀 푸들, 둥근 퍼프털
  - 구찌: 주황+하양 코숏, 긴 꼬리와 파란 눈
- 주먹/발차기/박치기/점프발차기 애니메이션을 전신 포즈 변화 방식으로 수정
- 아이템 드롭
  - 망치: J 공격이 강력한 망치 휘두르기로 3회 변경
  - 고기: 누적 피해 55% 회복
  - 무적별: 6초 무적
- 맵 선택
  - 집안 거실
  - 화장실
  - 아파트 산책로
- 연습용 봇 지원
- 5 KO 선승

## 조작
- WASD: 이동
- J: 주먹 / 망치 보유 시 망치
- K: 발차기
- L: 박치기
- Space: 점프
- 점프 중 K: 점프발차기
- Shift: 대시

## 기존 Render 사이트 업데이트
현재 Render Root Directory가 `byeongmat-animal-brawler/byeongmat-animal-brawler`라면 GitHub에서 그 **안쪽 폴더**를 연 뒤, 이 압축파일을 풀어서 나온 파일과 `public` 폴더를 그대로 업로드해 기존 파일을 덮어쓰면 됩니다.

폴더 자체를 다시 드래그하지 말고, 압축을 푼 뒤 보이는 `public`, `server.js`, `package.json` 등의 **내용물 전체**를 업로드하세요.
