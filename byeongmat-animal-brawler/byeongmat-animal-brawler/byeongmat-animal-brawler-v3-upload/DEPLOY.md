# 기존 사이트에 v3 올리기

1. GitHub 저장소 `Tofu-stew` 열기
2. `byeongmat-animal-brawler` 폴더 열기
3. 그 안의 `byeongmat-animal-brawler` 폴더를 한 번 더 열기
4. `Add file` → `Upload files`
5. v3 ZIP 압축을 풀고 보이는 내용물 전체(`public`, `server.js`, `package.json` 등)를 업로드
6. Commit changes
7. Render가 Auto-Deploy할 때까지 기다리기
8. Deploy succeeded / Live 확인
9. 게임 페이지에서 Ctrl+F5

주의: `byeongmat-animal-brawler` 폴더 자체를 업로드하면 폴더가 또 한 겹 생깁니다.
