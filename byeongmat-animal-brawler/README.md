# 병맛 동물 격투게임

친구에게 방 링크를 보내 2~4명이 브라우저에서 같이 플레이하는 3D 난투 게임입니다.

## 들어간 기능
- 2~4인 실시간 온라인 방
- 4자리 방 코드 + 초대 링크
- 캐릭터 3종
  - 뚱냥이: 무겁고 잘 안 날아감 / 배치기
  - 대갈병아리: 빠르고 공격적 / 로켓 박치기
  - 감자인간: 균형형 / 감자 회전
- 3인칭 카메라 + 마우스 시점
- WASD 이동 / Space 점프 / Shift 대시 / 좌클릭 공격 / E 특수기
- 피해량(%)이 쌓일수록 더 멀리 날아가는 넉백 시스템
- 낙사 후 자동 리스폰
- 5 KO 선승
- 중앙 회전 소시지 장애물
- 서버가 이동/피격/KO/점수를 판정

## 로컬 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.
같은 와이파이의 친구가 접속하려면 PC의 로컬 IP와 3000 포트를 이용할 수 있습니다.

## 인터넷 링크로 배포
이 프로젝트는 Node.js 서버가 필요합니다. `npm start`를 실행할 수 있고 WebSocket을 허용하는 Node 호스팅에 그대로 올리면 됩니다.

배포 설정:
- Build command: `npm install`
- Start command: `npm start`
- 환경변수 PORT는 호스팅 서비스가 자동으로 지정해도 동작합니다.

배포 후 생성된 주소로 접속해 방을 만든 다음, 게임 안의 `초대 링크 복사` 버튼을 친구에게 보내면 됩니다.

## 구조
- `server.js`: 방 관리, 물리/전투/KO/점수, Socket.IO 동기화
- `public/index.html`: 메뉴/대기실/HUD
- `public/style.css`: 화면 디자인
- `public/game.js`: Three.js 3D 렌더링, 캐릭터, 카메라, 입력, 이펙트

## 참고
현재는 프로토타입용 프리미티브 3D 캐릭터입니다. 나중에 직접 만든 `.glb/.gltf` 캐릭터와 애니메이션으로 교체하면 외형을 크게 업그레이드할 수 있습니다.

Three.js와 Socket.IO는 `npm install`로 함께 설치되므로 별도 CDN 설정은 필요하지 않습니다.
