# 병맛 동물 격투게임 리부트 v7 — 1차 완성도 개선

기존 v6의 Canvas 2D 구조와 PNG 스프라이트 20개를 유지한 상태에서 전투 손맛, 승패/결과, 맵 기믹, 캐릭터 소규모 특성, BOT 성격을 추가한 패치입니다.

## 유지한 핵심 구조
- Canvas 2D 전투 렌더링
- X/Y 평면 이동 + Z축 점프
- PNG 스프라이트 상태 교체 (`idle`, `punch`, `kick`, `jump`, `jumpkick`)
- 좌우 방향은 스프라이트 좌우 반전
- WASD / Space / J / K / Shift / ESC
- 누적 데미지 % → 데미지가 높을수록 넉백 증가
- 사방 장외, 스톡, 리스폰, down/getup
- BOT 0~3 선택
- 기존 아이템 5종
- 기존 맵 4종

## v7 핵심 변경

### 타격감
- 주먹 히트스톱 42ms
- 발차기 히트스톱 64ms
- 점프킥 히트스톱 82ms
- 높은 누적 데미지에서는 히트스톱이 최대 약 +18ms 증가
- 공격별 화면 흔들림 차등 적용
- 별 / 충격 스파크 / 먼지 파티클 추가
- 높은 데미지 상태에서 강하게 날아가면 짧은 이동 궤적 추가

### 공격 역할
- 주먹: 9 데미지 / 빠른 220ms 모션 / 약한 넉백
- 발차기: 14 데미지 / 350ms 모션 / 강한 넉백
- 점프킥: 16 데미지 / 강한 넉백 / 빗나가 착지 시 210ms 착지 딜레이
- 대시+J: 대시 펀치
- 대시+K: 돌진 킥
- 공중+J: 공중 주먹

### 스톡 / 승패 / 결과
- 기본 3 Stock
- 시작 화면에서 3 / 5 Stock 선택 가능
- 마지막 한 캐릭터만 스톡이 남으면 경기 종료
- 마지막 장외 시 FINAL OUT 연출
- 결과 화면에 플레이어별 통계/병맛 칭호 표시
- 다시 하기 / 캐릭터 선택으로 / 메인 메뉴 버튼 추가

### 캐릭터 소규모 특성
- 찌개 `튼튼한 말티푸`: 킥 계열 넉백 +7%
- 만두 `복슬복슬 쿠션`: 받는 넉백 -6%
- 감자 `아기 우다다`: 이동속도 +6%, 받는 넉백 +5%
- 구찌 `고양이 착지`: 공중 조작력 +12%, 착지 딜레이 35% 감소

### 맵 기믹
- 거실: 로봇청소기가 간헐적으로 지나가며 약하게 밀침
- 화장실: 보이는 물웅덩이에서 관성이 증가하고 방향 전환이 둔해짐
- 산책로: 경고 표시와 벨 후 킥보드가 정해진 라인을 통과하며 강하게 밀침
- 축구장: 공이 굴러다니고 공격/몸 충돌로 이동하며 빠른 공은 작은 넉백 발생

### 아이템
- 낙하 전 약 760ms 경고 원/느낌표 표시
- 중앙~중간 영역에 더 자주 떨어지도록 위치 분포 조정
- 아이템 그래픽 크기 확대
- 무적: 5초 → 3.8초
- 똥 효과 중 머리 위 💩 상태 표시 추가

### 공정성 / 리스폰
- 기상 완료 후 400ms 피격 보호
- 장외 리스폰 보호 900ms 유지
- 리스폰 시 다른 캐릭터와 겹치지 않도록 최대 10회 위치 탐색

### BOT 성격
생성 시 다음 중 하나를 랜덤 부여합니다.
- 공격형: 적극 접근, 킥 비율 증가
- 겁쟁이: 고데미지 시 중앙/회복·무적 아이템 우선
- 아이템광: 아이템 추적 우선
- 점프광: 점프/점프킥 비율 증가
