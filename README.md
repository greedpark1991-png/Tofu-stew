# 병맛 동물 격투게임 리부트

새로 다시 만든 초기 프로토타입입니다.

## 포함 내용
- 플레이 캐릭터 4종: 찌개 / 만두 / 감자 / 구찌
- 반측면 도트 스타일의 간단한 격투 애니메이션
- 맵 4종: 집 거실 / 집 화장실 / 아파트 산책로 / 축구 잔디밭
- 공격 3종: 펀치 / 킥 / 박치기
- 점프, 피격, 다운 / 기상
- 데미지가 쌓일수록 넉백 증가
- 장외 시 스톡 차감 후 리스폰
- 랜덤 아이템 드롭
- 싱글 플레이어 + 3 BOT

## 조작
- 이동: WASD
- 점프: Space
- 펀치: J
- 킥: K
- 박치기: L
- 대시: Shift
- 메뉴로 돌아가기: ESC

## 아이템
- 망치: 강화 타격 3회
- 무적: 5초 무적
- 스피드 약: 5초 동안 속도 1.3배
- 고기: 데미지 일부 회복
- 똥모양: 5초 동안 좌우 이동 반전

## 실행 방법
### 로컬
1. 폴더를 연다
2. 터미널에서 아래 명령 실행
   ```bash
   node server.js
   ```
3. 브라우저에서 `http://localhost:10000` 접속

### Render
- Web Service로 배포 가능
- Root Directory는 이 폴더 자체로 지정
- Start Command는 `node server.js`
- Docker 사용 시 `render.yaml` 또는 `Dockerfile` 그대로 사용 가능

## 참고
현재 버전은 **온라인 멀티가 아닌 싱글 + BOT 프로토타입**입니다.
우선은 게임 감과 구조를 다시 잡는 데 초점을 맞췄습니다.
