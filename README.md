# 병맛 동물 격투게임 리부트 v3

더 귀여운 치비 반측면 스타일로 다시 다듬은 버전입니다.

## 포함 내용
- 플레이 캐릭터 4종: 찌개 / 만두 / 감자 / 구찌
- 반측면 치비 도트 렌더링
- 전투 모션: 주먹 / 발차기 / 점프 / 점프 발차기 / 피격 / 다운 / 기상
- 맵 4종: 집 거실 / 집 화장실 / 아파트 산책로 / 축구 잔디밭
- 랜덤 아이템: 망치 / 무적 / 스피드약 / 고기 / 똥모양
- 기본 시작 시 BOT 0마리, 원하는 수만 추가 가능

## 실행
```bash
npm install
npm start
```

기본 포트는 3000입니다.
