# 병맛 동물 격투게임 REBOOT

> 수정 메모 (2026-09-08): 사용자 최종 확인에 따라 원본 기준 이미지를 다시 고정했습니다.
> - 감자 = 작은 크림색 아기 토이푸들 원본 PNG
> - 만두 = 하얗고 복슬복슬한 푸들 원본 PNG
> 본 수정본은 위 두 장을 그대로 `public/assets/source-originals/` 및 게임 런타임 캐릭터 자산에 반영한 버전입니다.

찌개 / 만두 / 감자 / 구찌 **4마리만** 등장하는 캐주얼 2D 장외 난투 게임입니다.

이번 REBOOT은 기존 프로젝트 코드를 이어붙이지 않고 새로 만든 독립 프로젝트이며, 핵심 우선순위는 복잡한 격투 시스템보다 **원본 캐릭터가 실제 게임 화면에서 귀엽게 움직이며 싸우는 것**입니다.

## 실행 방법

### Windows 빠른 실행

- Node.js 18 이상이 설치되어 있다면 프로젝트 루트의 `START_GAME.bat`를 더블클릭하면 서버를 띄우고 브라우저를 엽니다.

### Node.js로 실행

1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 터미널 실행
3. `npm start`
4. 브라우저에서 `http://localhost:8080` 접속

외부 패키지가 없어서 `npm install`은 필요하지 않습니다.

### 다른 정적 서버 사용

`public` 폴더를 아무 정적 웹 서버로 열어도 됩니다. 이미지 로딩 안정성을 위해 `file://` 직접 실행보다 로컬 서버를 권장합니다.

## 조작법

- `A / D`: 좌우 이동
- `W`: 공중에서 위쪽 이동 보조
- `S`: 빠르게 내려가기 / 위 플랫폼 아래로 통과
- `Space`: 점프
- `J`: 빠른 공격
- `K`: 강한 공격
- `Shift`: 대시
- `ESC`: 일시정지

복잡한 가드 / 잡기 / 필살기 / 커맨드 / 콤보 입력은 없습니다.

## 게임 규칙

- 플레이어 1명 + BOT 3명이 동시에 싸웁니다.
- 모든 캐릭터는 **3 Stock**으로 시작합니다.
- 공격을 맞으면 HP 대신 **누적 데미지 %**가 올라갑니다.
- 누적 데미지가 높을수록 다음 공격에 더 멀리 날아갑니다.
- 화면 밖으로 날아가면 Stock 1개를 잃고, 0%로 재등장합니다.
- 마지막까지 Stock이 남은 캐릭터가 승리합니다.

## 캐릭터

### 찌개 — 갈색 말티푸
- 든든한 기본형
- 무게 / 속도 / 공격력이 가장 평균적입니다.

### 만두 — 하얀 푸들
- 복슬복슬 생존형
- 조금 묵직해서 같은 데미지에서도 덜 날아갑니다.

### 감자 — 작고 아기 같은 크림색 토이푸들
- 작은 우다다
- 네 마리 중 화면상 체구가 가장 작고 빠르지만 가볍습니다.

### 구찌 — 주황+흰색 코리안숏헤어
- 날렵한 냥펀치
- 빠른 이동과 살짝 강한 타격이 특징입니다.

## 원본 PNG 반영 방식

`public/assets/source-originals/`에 네 캐릭터의 정식 원본 PNG를 그대로 보존했습니다.

게임에서 사용하는 `public/assets/characters/` 이미지는 원본의 **투명 여백만 잘라내고 nearest-neighbor 방식으로 축소한 런타임용 사본**입니다. 얼굴 / 눈 위치 / 귀 / 털 무늬 / 체형을 다시 그리거나 임의 수정하지 않았습니다.

공격 프레임이 완전한 애니메이션 세트가 아니기 때문에, 다른 동물 그림이나 사람형 임시 스프라이트를 섞지 않았습니다. 대신 원본 캐릭터 **전체 몸 이미지 자체**에 다음과 같은 가벼운 모션만 적용합니다.

- idle: 아주 약한 breathing / bob
- 이동: 몸 전체가 통통 튀는 이동 bob
- 빠른 공격: 몸 전체가 살짝 뒤로 모였다가 앞으로 툭 기울며 lunge
- 강한 공격: 몸 전체가 더 크게 눌렸다가 앞으로 길게 튀어나오는 squash / stretch
- 점프: 몸 전체가 세로로 약간 늘어나고 기울어짐
- 대시: 몸 전체가 가로로 살짝 늘어나며 전진
- 피격: 몸 전체가 뒤로 기울고 짧게 흰색 flash

**팔이나 다리만 따로 생성하거나, 캐릭터 옆에 막대/히트박스를 공격 그래픽으로 노출하지 않습니다.** 충돌 판정은 보이지 않는 로직일 뿐 화면에는 항상 네 동물 PNG만 플레이어 캐릭터로 보입니다.

## 아이템 6종

- 🔨 **망치**: 다음 공격 3회 강화
- 🍖 **고기**: 현재 누적 데미지 25% 감소
- 🦴 **스피드 간식**: 6초간 이동속도 상승
- ⭐ **별사탕**: 3초간 무적
- 💩 **똥**: 가까운 상대의 이동 방향을 잠시 뒤집음
- 🐤 **삑삑이**: 주변 전체에 짧은 충격파

## 맵 4종

### 폭신폭신 거실
- 따뜻한 생활형 거실
- 소파 구간을 빠르게 밟으면 통통 튀어 오릅니다.

### 미끌미끌 화장실
- 밝은 타일 화장실
- 주기적으로 변기 쪽에서 바람이 불어 캐릭터를 왼쪽으로 밉니다.

### 아파트 산책로
- 나무와 벤치가 있는 산책길
- 중앙 스프링클러가 가끔 분사되어 위로 밀어 올립니다.

### 동네 축구장
- 초록 잔디 축구장
- 주기적으로 축구공이 굴러와 맞은 캐릭터를 날립니다.

## 타격감

- 공격 타이밍과 동기화된 보이지 않는 히트박스
- 누적 데미지에 비례한 넉백

## 개발 원칙

- 플레이어 캐릭터는 찌개 / 만두 / 감자 / 구찌 외에 추가하지 않음
- 로봇 / 마네킹 / 사람형 / 네모 / 원형 placeholder 캐릭터 없음
- 캐릭터 디자인은 원본 PNG 기준
- 공격은 캐릭터 전체 몸의 움직임으로 보이게 함
- 기능 수보다 귀여움 / 캐릭터 인상 / 병맛 상황을 우선
