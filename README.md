# 멍냥대난투 — 4인 온라인 웹 난투 게임

브라우저 링크 하나로 친구들과 최대 4명이 동시에 접속해 싸우는 도트 난투 게임입니다.

## 현재 구현된 것

- 최대 4인 온라인 실시간 대전 (Socket.IO)
- 방 만들기 / 5자리 방 코드 / 초대 링크 복사
- 4캐릭터: 찌개(갈색 말티푸), 만두(하얀 푸들), 감자(크림색 아기 말티푸), 구찌(주황·하양 코숏)
- 캐릭터 능력치는 모두 동일, 외형만 다름
- 벨트스크롤식 상하좌우 이동
- 조작: 방향키 이동 / Z 펀치 / X 킥 / Space 점프 / 공중 X 점프킥
- 공격 피격 스파크, 주먹 바람 효과, 피격/그로기/승리 표정
- 맵 2종
  - 옥상 링: 퍼센트 누적 → 맞을수록 넉백 증가 → 화면 밖 장외. 3목숨
  - 도장: 사방 벽 → HP 100 → HP가 0이 되면 KO. 3목숨
- 화면 상단에 캐릭터별 퍼센트 또는 HP + 남은 목숨 표시
- 서버 판정 기반 이동/공격/피격

## 로컬 실행

Node.js 20 이상 권장.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## GitHub + Render Dashboard로 배포하기

GitHub Pages만으로는 실시간 Socket.IO 서버를 돌릴 수 없기 때문에, GitHub에는 코드를 보관하고 Render Dashboard에서 이 저장소를 Web Service로 배포하는 방식이 가장 간단합니다.

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일 전체를 저장소에 업로드합니다.
3. Render Dashboard → New → Web Service → GitHub 저장소 연결.
4. 설정은 아래처럼 잡습니다.
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Deploy 후 Render가 만들어 준 `https://...onrender.com` 주소가 게임 링크입니다.
6. 게임에서 방 만들기 → 초대 링크 복사 → 친구들에게 전송하면 됩니다.

저장소 루트의 `render.yaml`을 이용해 Blueprint 방식으로 배포해도 됩니다.

## 게임 규칙

### 옥상 링 — 장외 모드

0%에서 시작. 맞을 때마다 퍼센트가 오르고 같은 공격이라도 퍼센트가 높을수록 더 멀리 날아갑니다. 화면 바깥으로 완전히 밀려나면 목숨 1개를 잃고 다시 등장합니다. 3번 장외되면 탈락합니다.

### 도장 — HP 모드

HP 100에서 시작. 사방이 벽으로 막혀 장외되지 않습니다. HP가 0이 되면 목숨 1개를 잃고 다시 등장합니다. 3번 KO되면 탈락합니다.
