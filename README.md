# 병맛 동물 격투게임 리부트 v2

## 이번 버전 핵심
- 찌개 / 만두 / 감자 / 구찌 4마리를 **반측면 2~3등신 치비 도트**로 다시 그림
- 박치기 삭제
- 주먹 / 발차기 / 점프 / 공중 발차기만 사용
- BOT은 자동 생성되지 않고 메뉴에서 0~3마리 선택
- 아이템 크기 확대 및 이름 표시
- 망치 3회 강화 / 무적 5초 / 스피드업 5초 / 고기 회복 / 똥 좌우반전 5초
- 데미지가 쌓일수록 넉백 증가
- 맵 바깥으로 밀리면 장외
- 맵 4종: 거실 / 화장실 / 아파트 산책로 / 축구 잔디밭
- 각 맵에 장소를 알아볼 수 있는 대표 오브젝트 추가

## 조작
- WASD: 이동
- Space: 점프
- J: 주먹
- K: 발차기
- 공중 K: 점프 발차기
- Shift: 대시
- ESC: 메뉴

## 실행
```bash
node server.js
```
브라우저에서 `http://localhost:10000` 접속.

## Render
저장소 루트에 이 폴더 안의 파일을 업로드하고 Root Directory는 빈칸으로 두면 됩니다.
