# 병맛 동물 격투게임 v7.2 — 원본 맵/BGM 보존 완성도 개선판

이번 버전은 리부트 과정에서 사라졌던 원본 요소를 복구한 뒤, v7.1의 전투 완성도 개선만 합친 버전입니다.

## 원본에서 복구/유지한 핵심
- 맵 2종: **옥상 링 / 멍냥 도장**
- 오프닝·메뉴 BGM: `Cold_Bell_Impact.mp3`
- 전투 시작 BGM: `The_Rooftop_Bout.mp3`
- BGM 기본 음량 18%, SFX 기본 음량 72%, `localStorage` 저장
- 찌개 / 만두 / 감자 / 구찌의 기존 PNG 스프라이트 20개
- PNG 상태 교체 방식: idle / punch / kick / jump / jumpkick
- 좌우 방향은 PNG 좌우 반전
- Canvas 2D 렌더링

## 유지한 1차 완성도 개선
- 누적 데미지 + 데미지가 높을수록 증가하는 넉백
- 사방 장외 / 3 또는 5 Stock / 리스폰
- 주먹 / 발차기 / 점프 발차기 역할 분리
- 대시+J 대시 펀치 / 대시+K 돌진 킥 / 공중+J 공중 주먹
- 히트스톱 / 화면 흔들림 / 타격 파티클 / 강한 넉백 궤적
- 점프킥 실패 착지 딜레이
- 마지막 KO 연출 / 승자 판정 / 결과 화면 / 경기 통계 / 병맛 칭호
- 4캐릭터 작은 특성
- BOT 0~3 / 공격형·겁쟁이·아이템광·점프광
- 망치 / 무적 / 스피드약 / 고기 / 똥 아이템
- 아이템 낙하 경고 및 중앙 집중 스폰
- 기상 400ms 보호 / 리스폰 900ms 보호 및 겹침 완화
- 최근 공격자 2.2초 기반 장외 기록 / 자살 장외 기록

## v7.2 맵 기믹
- **옥상 링:** 충분한 경고 후 짧게 부는 약한 강풍. 데미지는 없고 살짝 밀기만 합니다.
- **멍냥 도장:** 중앙에 눈에 보이는 광택 마루. 해당 구역에서만 관성이 조금 커집니다.

맵 기믹은 전투보다 강하지 않으며, 장외 사고를 조금 만드는 수준으로 제한했습니다.

## 실제 전투 수치
| 공격 | 데미지 | 전체 모션 | 사거리 | 기본 넉백 | 히트스톱 |
|---|---:|---:|---:|---:|---:|
| 주먹 J | 9 | 220ms | 32 | 2.9 | 42ms |
| 발차기 K | 14 | 350ms | 45 | 4.4 | 64ms |
| 점프킥 공중 K | 16 | 300ms | 43 | 4.9 | 82ms |
| 대시 펀치 Shift+J | 11 | 270ms | 40 | 3.55 | 50ms |
| 돌진 킥 Shift+K | 15 | 390ms | 50 | 4.7 | 70ms |
| 공중 주먹 공중 J | 8 | 215ms | 30 | 2.6 | 38ms |

넉백 기본식: `공격 기본 넉백 + 상대 누적 데미지 × 0.052`에 캐릭터 특성을 적용합니다.

## 실행
```bash
npm start
```
기본 포트는 `10000`이며 Render에서는 `PORT` 환경변수를 사용합니다.

## 배포
GitHub 저장소 최상단에 이 폴더의 **내용물**을 올리고 Render의 Root Directory는 비워 둡니다.
